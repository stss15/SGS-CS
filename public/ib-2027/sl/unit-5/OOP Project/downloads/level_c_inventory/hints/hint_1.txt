=== HINT 1: Understanding the Inventory Class ===

GOAL:
Create an Inventory class that stores and manages items.
Then give the Player an inventory!

TWO PARTS TO THIS LEVEL:
  1. Create the Inventory class (student/inventory.py)
  2. Modify Player to HAVE an Inventory (student/player.py)

WHAT THE INVENTORY NEEDS:
  - A class variable MAX_CAPACITY (how many items fit)
  - A way to store items (hint: use a list)
  - Methods to add, remove, check, count, and list items

WHAT IS A CLASS VARIABLE?
  - A variable shared by ALL instances
  - Defined outside __init__, inside the class
  - Example:
      class Inventory:
          MAX_CAPACITY = 5  # Class variable - same for everyone

WHERE TO START:
  1. Open student/inventory.py
  2. Define MAX_CAPACITY as a class variable
  3. In __init__, create an empty list for items
