---------------------------------------------
PLAYER CLASS UPDATE
---------------------------------------------

In player.py, you need to:
  1. Import Inventory at the top of the file
  2. In __init__, create self.inventory = Inventory()

This is COMPOSITION: Player HAS-A Inventory
(Different from inheritance, which is IS-A)

---------------------------------------------
COMMON MISTAKES
---------------------------------------------

✗ Putting MAX_CAPACITY inside __init__
    → It's a CLASS variable, so put it outside

✗ Forgetting to return True/False from add/remove
    → The game engine checks these return values!

✗ Returning the actual _items list instead of a copy
    → This lets external code modify your internal list
