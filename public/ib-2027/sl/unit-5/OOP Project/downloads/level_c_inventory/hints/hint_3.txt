=== HINT 3: Putting It All Together ===

Now you need to do TWO things:
  1. Complete the Inventory class
  2. Add an Inventory to the Player class

---------------------------------------------
INVENTORY CLASS STRUCTURE
---------------------------------------------

Build these parts:
  - Class variable: MAX_CAPACITY (use the given value)
  - __init__: create an empty list called _items
  - add: reject if full or duplicate; otherwise add and return True
  - remove: remove if present; otherwise return False
  - has_item, list_items, count, is_full

HINTS FOR EACH METHOD:
  - add: Use 'in' to check for duplicates
  - remove: Use list's remove() method
  - has_item: Just return a boolean expression
  - list_items: Return a COPY (use .copy())
  - count: Use len()
  - is_full: Compare count to MAX_CAPACITY

---------------------------------------------
PLAYER CLASS UPDATE
---------------------------------------------

In player.py, you need to:
  1. Import Inventory at the top of the file
  2. In __init__, create a new Inventory and store it in self.inventory

This is COMPOSITION: Player HAS-A Inventory
(Different from inheritance, which is IS-A)

---------------------------------------------
COMMON MISTAKES
---------------------------------------------

✗ Putting MAX_CAPACITY inside __init__
    → It's a CLASS variable, so put it outside

✗ Forgetting to return True/False from add/remove
    → The game engine checks these return values!

✗ Returning the actual _items list instead of a copy
    → This lets external code modify your internal list
