=== HINT 2: Inventory Methods ===

THE METHODS YOU NEED:

---------------------------------------------
add(item_name)
---------------------------------------------
  - Returns True if item was added
  - Returns False if can't add (full or duplicate)
  - Don't allow duplicates!
  - Don't exceed MAX_CAPACITY!

  Pattern:
    def add(self, item_name):
        if self.is_full():
            return False
        if item_name in self._items:
            return False
        self._items.append(item_name)
        return True

---------------------------------------------
remove(item_name)
---------------------------------------------
  - Returns True if item was removed
  - Returns False if item wasn't there

---------------------------------------------
has_item(item_name)
---------------------------------------------
  - Returns True if inventory contains this item
  - Returns False otherwise
  - Hint: use 'in' keyword

---------------------------------------------
list_items()
---------------------------------------------
  - Returns a LIST of all items
  - Hint: return a COPY to prevent external modification

---------------------------------------------
count()
---------------------------------------------
  - Returns how many items are in inventory
  - Hint: use len()

---------------------------------------------
is_full()
---------------------------------------------
  - Returns True if at MAX_CAPACITY
  - Returns False otherwise
