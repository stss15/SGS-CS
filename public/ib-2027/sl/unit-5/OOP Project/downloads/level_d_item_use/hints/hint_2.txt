=== HINT 2: Implementing the Methods ===

INVENTORY.CONSUME(item_name)
---------------------------------------------
- This method should remove an item and report success
- It can reuse the same logic as remove()
- Return True if the item was removed, False if it wasn't there

PLAYER.USE_ITEM(item_name, target)
---------------------------------------------
This method needs to:
1) Check if the player has the item
2) If not, return an error message
3) If yes, check which item it is
4) Apply the appropriate effect
5) Consume the item if needed
6) Return a description of what happened

KNOWN ITEMS:
- med_patch -> Use on "self" to heal
- ration_pack -> Use on "self" for food
- keycard -> Use on doors to unlock them
- torch -> Lights up dark areas

THE SIGNATURE:
use_item(self, item_name, target)
