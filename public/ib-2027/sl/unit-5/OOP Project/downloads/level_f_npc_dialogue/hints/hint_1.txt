=== HINT 1: Understanding NPC Dialogue ===

GOAL:
When the player talks to an NPC, your method handles 
the conversation by showing options and getting input.

THE METHOD:
  def respond_to_npc(self, npc_name, dialogue_tree):
      # Handle the conversation
      # Return the outcome

WHAT YOU RECEIVE:
  - npc_name: Name of the NPC (e.g., "Dr. Chen")
  - dialogue_tree: A dictionary with:
      - "greeting": What the NPC says
      - "options": List of things player can say
      - "responses": What NPC says back for each option

EXAMPLE DIALOGUE TREE:
  {
      "greeting": "Hello, survivor. Need help?",
      "options": ["Ask about the station", "Ask for supplies"],
      "responses": ["The station is damaged...", "I can spare a med-patch."]
  }
