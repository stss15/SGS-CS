=== HINT 2: Input Handling Pattern ===

THE FLOW:
  1. Print the NPC's greeting
  2. Show numbered options to the player
  3. Get player's choice using input()
  4. Validate the choice
  5. Print the NPC's response
  6. Return the chosen option index

SHOWING OPTIONS:
  for i, option in enumerate(dialogue_tree["options"]):
      print(f"  {i+1}. {option}")

GETTING INPUT:
  choice = input("Enter choice: ").strip()

VALIDATING:
  - Convert to integer
  - Check if in valid range
  - Handle invalid input gracefully
