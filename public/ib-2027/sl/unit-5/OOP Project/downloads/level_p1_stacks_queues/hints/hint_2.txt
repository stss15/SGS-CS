=== HINT 2: The Stack Class ===

REQUIREMENTS:
  - Use a list for storage: self._items = []
  - Push adds to END of list (use append)
  - Pop removes from END of list (use list's pop method)

STRUCTURE (in words):
  - __init__: create an empty list called _items
  - push: add item to end of the list
  - pop: if empty return None; otherwise remove and return last item
  - peek: if empty return None; otherwise return last item without removing
  - is_empty: return True if no items, False otherwise
  - size: return the number of items

---------------------------------------------
KEY HINTS
---------------------------------------------
  - List's append() adds to end
  - List's pop() removes from end (no argument needed)
  - Check is_empty() before trying to pop/peek

---------------------------------------------
WHY LIFO?
---------------------------------------------
  push(A), push(B), push(C)
  List is now: [A, B, C]
  
  pop() returns C  (last in, first out)
  List is now: [A, B]
