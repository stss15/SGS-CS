=== HINT 2: Setting Up Attributes in __init__ ===

THE PATTERN:
Every attribute needs to be set using self.attributename = value

FOR THIS LEVEL, THE PLAYER NEEDS:
  - name       → The name passed in as a parameter
  - health     → Starting health (100)
  - max_health → Maximum health cap (100)
  - armour     → Damage reduction (2)
  - accuracy   → Hit chance percentage (85)

EXAMPLE:
  def __init__(self, name):
      self.name = name        # Use the parameter
      self.health = 100       # Fixed starting value
      # ... add the rest

COMMON MISTAKES:
  ✗ Forgetting 'self' before the attribute name
  ✗ Not including 'self' as the first parameter
  ✗ Forgetting to set max_health (it's different from health!)

REMEMBER:
  - 'self' refers to THIS specific player object
  - Each player you create gets their own copy of these values
