=== HINT 2: The Two Methods ===

CHOOSE_ACTION(options)
---------------------------------------------
  - options is a list like ["attack", "defend", "flee"]
  - Show the options to the player
  - Get their choice
  - Return the chosen action string

Example:
  def choose_action(self, options):
      print("What do you do?")
      for i, opt in enumerate(options):
          print(f"  {i+1}. {opt}")
      # Get input and return choice
      ...

COMPUTE_DAMAGE(base_damage, armour)
---------------------------------------------
  - Calculate: damage = base_damage - armour
  - IMPORTANT: Damage cannot be negative!
  - Return 0 if armour exceeds base_damage

Example calculations:
  compute_damage(20, 5)  → 15
  compute_damage(5, 5)   → 0
  compute_damage(5, 20)  → 0 (not -15!)
