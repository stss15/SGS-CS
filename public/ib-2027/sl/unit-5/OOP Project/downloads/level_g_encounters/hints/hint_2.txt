=== HINT 2: The Two Methods ===

CHOOSE_ACTION(options)
---------------------------------------------
- options is a list like ["Attack", "Defend", "Use Item", "Run"]
- The engine already prints the numbered list
- You only need to:
  1) ask for input
  2) validate it's a number in range
  3) return the 0-based index

COMPUTE_DAMAGE(base_damage, armour)
---------------------------------------------
- Final damage = base_damage - armour
- Damage cannot be negative (clamp at 0)

Example results (not code):
- base 20, armour 5  => damage 15
- base 5, armour 5   => damage 0
- base 5, armour 20  => damage 0
