=== HINT 3: Method Patterns ===

TO_SAVE_DATA:
- Return a dictionary containing ALL player state
- Include: name, player_type, health, max_health, armour, accuracy
- Include inventory as a list of item IDs

FROM_SAVE_DATA (@classmethod):
- Create a new instance using the saved name
- Restore each attribute from the dictionary
- Rebuild inventory by adding each item ID
- Return the new Player object

KEY CONCEPTS:
- @classmethod makes it callable on the class
- Round-trip: to_save_data -> from_save_data restores the same state
- Inventory should be a list in saved data

TESTING IDEA:
Create a player, save to dict, reload, and compare fields.

Run validate.py to check your work!
