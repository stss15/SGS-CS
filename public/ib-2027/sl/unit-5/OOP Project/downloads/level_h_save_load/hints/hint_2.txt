=== HINT 2: The Two Methods ===

TO_SAVE_DATA()
---------------------------------------------
Returns a dictionary with everything that needs saving:
  - name
  - health
  - max_health
  - inventory items
  - any other state

  def to_save_data(self):
      return {
          "name": self.name,
          "health": self.health,
          # ... more fields
      }

FROM_SAVE_DATA(data) - CLASS METHOD
---------------------------------------------
This is different! It's a CLASS METHOD, not an instance method.
It creates a NEW Player from the data.

  @classmethod
  def from_save_data(cls, data):
      # Create a new player
      # Restore all the saved values
      # Return it

WHAT IS @classmethod?
  - Called on the class, not an instance
  - First argument is 'cls' (the class itself)
  - Can be called like: Player.from_save_data(data)
