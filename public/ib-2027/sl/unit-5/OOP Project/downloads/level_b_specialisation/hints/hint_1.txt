=== HINT 1: Understanding Inheritance ===

GOAL:
Create TWO new classes (Brute and Scout) that INHERIT from Player.

WHAT IS INHERITANCE?
  - A way to create new classes based on existing ones
  - The new class (child) gets all attributes/methods from the old class (parent)
  - You only write the DIFFERENCES

EXAMPLE STRUCTURE:
  class Brute(Player):    # The (Player) means "inherits from Player"
      def __init__(self, name):
          # Call the parent's __init__ first
          # Then change whatever is different
          pass

  3. Make sure you import Player at the top!
