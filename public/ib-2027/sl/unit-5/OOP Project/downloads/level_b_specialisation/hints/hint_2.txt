=== HINT 2: Using super().__init__() ===

THE KEY CONCEPT:
When a child class inherits from a parent, it needs to CALL the 
parent's __init__ to set up the inherited attributes.

THE MAGIC LINE:
  super().__init__(name)

This calls Player's __init__, which sets up:
  - self.name
  - self.health = 100
  - self.max_health = 100
  - self.armour = 2
  - self.accuracy = 85

THEN YOU OVERRIDE THE DIFFERENCES:
  class Brute(Player):
      def __init__(self, name):
          super().__init__(name)    # Set up like normal Player
          self.health = 120         # Override with Brute values
          self.max_health = 120
          # ... and so on

BRUTE STATS:
  - health: 120
  - max_health: 120
  - armour: 3
  - accuracy: 70

SCOUT STATS:
  - health: 80
  - max_health: 80
  - armour: 1
  - accuracy: 95
