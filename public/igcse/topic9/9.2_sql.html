The Big Question

How do you find a needle in a haystack?

If the haystack is a database with millions of rows…

You don’t search manually — you ask for it.

✅ SQL (Structured Query Language) is how we “talk” to databases.

We describe what we want, and the database finds it.

Learn the magic words

Did You Know?

SQL Is Declarative

You describe what you want (e.g., “students with Score > 80”).

The database decides how to find it efficiently.

Keywords Are Usually Uppercase

SQL is often written with keywords like SELECT and WHERE in uppercase for readability.

It helps you spot the structure of a query quickly.

The Three Magic Words

SELECT

Which columns do you want?

FROM

Which table is the data in?

WHERE

Which rows match your condition?

Build a query step-by-step

Building a Query

Question: Show the names of students in Red house.

SELECT FirstName, Surname
FROM Students
WHERE House = 'Red'

SELECT

FirstName, Surname

(the columns we want)

FROM

Students

(the table name)

WHERE

House = 'Red'

(the filter)

The Result

FirstName Surname
Ali Khan
John Smith

Note: Only shows the columns we asked for, and only rows matching the condition!

Quick Check

What does SELECT * return?

All columns from the table (rows are filtered using WHERE).

SQL Syntax Rules

SELECT *

The asterisk means "all columns".

SELECT * FROM Students

Text in Quotes

Text values need single quotes.

WHERE House = 'Red'

Numbers: No Quotes

Numbers don't need quotes.

WHERE Age = 14

Not Case Sensitive

SELECT = select = SeLeCt

But we write keywords in CAPS by convention.

Multiple Conditions

What if we need more specific filters?

AND

Both conditions must be true.

OR

Either condition can be true.

NOT

The opposite of the condition.

Examples

AND Example

Question: Students in Red house who are 14.

SELECT FirstName, Surname
FROM Students
WHERE House = 'Red' AND Age = 14

Result: Ali Khan, John Smith (both Red AND 14)

OR Example

Question: Students in Red OR Blue house.

SELECT FirstName, Surname
FROM Students
WHERE House = 'Red' OR House = 'Blue'

Result: All 4 students (everyone is in Red or Blue!)

ORDER BY

How do we sort the results?

ASC

Ascending order (A→Z, 0→9)

Default if not specified.

DESC

Descending order (Z→A, 9→0)

See examples

ORDER BY Examples

Sort by surname alphabetically:

SELECT * FROM Students
ORDER BY Surname ASC

Sort by score (highest first):

SELECT * FROM Students
ORDER BY Score DESC

Result: John (91), Mei (88), Ali (85), Sara (72)

Quick Check

What does ORDER BY Score DESC do?

Sorts the results by Score from highest to lowest.

COUNT and SUM

What if we want to count or add up values?

COUNT

Counts how many records match.

SUM

Adds up all values in a column.

Examples

Function Examples

How many students in Red house?

SELECT COUNT(StudentID)
FROM Students
WHERE House = 'Red'

Result: 2

What's the total of all scores?

SELECT SUM(Score)
FROM Students

Result: 336 (85 + 72 + 91 + 88)

True or False?

Check Your Understanding

  1. SELECT * returns all rows.
  2. Numbers in WHERE need quotes.
  3. ORDER BY defaults to ascending.

Press Down to reveal answers

Question 1

SELECT * returns all rows.

Answer: FALSE

SELECT * returns all columns. WHERE filters which rows are returned.

Question 2

Numbers in WHERE need quotes.

Answer: FALSE

Only text values need quotes. Numbers are written without quotes: WHERE Age = 14

Question 3

ORDER BY defaults to ascending.

Answer: TRUE

If you don't specify ASC or DESC, it defaults to ASC (A→Z, 0→9).

Key Takeaways

🔎 SELECT chooses columns; FROM chooses the table

🎯 WHERE filters rows (text in quotes, numbers without)

🧠 Use AND/OR/NOT to combine conditions

↕️ ORDER BY sorts results (ASC or DESC)

🧮 COUNT counts rows; SUM adds values
