NASA's first planetary mission.

Exploded 293 seconds after launch.

A missing hyphen (-) in the code.

So we learn how to identify error types quickly.

Types of Errors

Grammar vs Meaning

Syntax Error

"Me Tarzan, You Jane"

Bad grammar. The computer doesn't understand.

Program Crashes.

Logic Error

"Turn Left" (when you meant Right)

Perfect grammar. Wrong instruction.

Program Runs (but fails).

Did You Know?

Debugging Takes Real Time

In real projects, a big part of development is finding and fixing bugs.

Knowing the type of error helps you fix it faster.

Error Type = Best Tool

Syntax: error messages/line numbers

Logic: trace tables and dry runs

Runtime: test data and handling unexpected cases

Syntax Errors

Breaking the Rules

Every language has rules. If you break them, the code won't run.

Error: Misspelled Command (PRINT).

  OUTPUT "Adult"

Error: Missing THEN.

Total = (5 + 10

Error: Missing closing bracket ).

Logic Errors

The Silent Killer

The code runs perfectly... but gives the wrong answer.

Harder to find because the computer doesn't tell you!

Bug Hunter: Level 2

Bug Hunter: Level 2

Find the Logic Errors.

Goal: Average of A and B.

Average <- A + B / 2

Error: Order of Operations (BODMAS).

Fix: (A + B) / 2

Goal: Loop 10 times.

FOR K <- 1 TO 100
  OUTPUT K
NEXT K

Error: Wrong loop limit.

Fix: 1 TO 10

Goal: Check if Adult (18+).

IF Age > 18 THEN
  OUTPUT "Adult"
ENDIF

Error: Excludes 18 year olds.

Fix: >= 18

Runtime Errors

Runs… then crashes

A runtime error happens while the program is running.

The syntax is correct, but something impossible happens (e.g., divide by 0).

Bug Hunter: Level 3

Bug Hunter: Level 3

Spot the runtime errors.

Problem: Divide by zero.

Result <- 10 / 0
OUTPUT Result

Fix: Check the denominator is not 0 before dividing.

Problem: Invalid array index.

Names[1] <- "Ali"
Names[2] <- "Bea"
OUTPUT Names[3]

Fix: Make sure the index exists (array bounds).

Problem: Unexpected input causes a crash.

INPUT Age
OUTPUT 100 / Age

Fix: Validate input and handle invalid values.

True or False?

Misconception Check

  1. A Syntax Error allows the program to run but gives wrong results.
  2. Trace Tables are useful for finding Logic Errors.
  3. Misspelling a variable name is a Logic Error.

Press Down to reveal answers

Question 1

A Syntax Error allows the program to run but gives wrong results.

Answer: False

That describes a Logic Error. A Syntax Error prevents the program from running at all.

Question 2

Trace Tables are useful for finding Logic Errors.

Answer: True

By stepping through manually, you can see exactly where the values go wrong.

Question 3

Misspelling a variable name is a Logic Error.

Answer: False

It is usually a Syntax Error (Undeclared Identifier), unless you accidentally spell another valid variable's name!

Key Takeaways

🧩 Syntax errors: break language rules — code won’t run

🧠 Logic errors: runs, but gives the wrong result

💥 Runtime errors: crash while running (e.g., divide by 0)

🔎 Use error messages for syntax

📋 Use trace tables for logic

🧪 Use test data to trigger and prevent runtime issues
