The Big Question

🤔 Are these two things the same?

"The Internet" vs "The World Wide Web"

❌ Most people think they're the same thing...

Even news reporters say "surfing the internet" when they mean "browsing websites"

✅ They're completely different!

One is the road. One is what's on the road.

Let's Build an Analogy

🛣️ Think of your country's road network...

The roads connect every city, town, and village.

But the roads themselves aren't the shops and services.

The Internet = The Roads (physical infrastructure)

The WWW = The Shops (services that use the roads)

Deep Dive: The Details

The Internet

What It Is

A worldwide collection of INTERconnected NETworks

The physical infrastructure

Cables, routers, satellites, data centres

Did You Know?

99% of international data travels through undersea cables!

There are over 400 submarine cables totaling 1.3 million km

That's enough to wrap around Earth 32 times 🌍

The World Wide Web

What It Is

A service that runs ON the Internet

A collection of web pages

Accessed via browsers using HTTP/HTTPS

Did You Know?

Tim Berners-Lee invented the WWW in 1989

The first website is still online!

Deep Dive: HTTP vs HTTPS

HTTP vs HTTPS

The Postcard vs The Safe

HTTP

📬

Like sending a postcard

Anyone handling it can read your message

HTTPS

📦🔒

Like sending a locked box

Only the recipient can open it

HTTP

Hypertext Transfer Protocol

Data sent in plain text

Can be intercepted and read

⚠️ Never enter passwords on HTTP sites!

HTTPS

HTTP + Secure

Uses SSL/TLS encryption

Data is scrambled in transit

✅ Look for the padlock!

The Phone Book of the Internet

You type www.google.com

But computers only understand numbers like 142.250.191.14

How does this translation happen?

DNS = Domain Name System

Like a phone book: converts names → numbers

Step-by-Step: The DNS Journey

Step 1: You Type a URL

🧑‍💻 → www.google.com

Your browser doesn't know where this is!

It needs to find the IP address

Step 2: Ask the DNS

🖥️ → 📖 "Where is google.com?"

Browser sends request to a DNS Server

The DNS server is like a phone book

Step 3: DNS Lookup

📖 Searching...

google.com → 142.250.191.14

If it doesn't know, it asks another DNS server

Step 4: IP Returned

📖 → 🖥️ "It's at 142.250.191.14!"

DNS sends the IP address back to your browser

Step 5: Connect & Load

🖥️ → 🌐 Request sent to IP address

Server sends HTML files back

Browser renders the page

⚡ All of this happens in milliseconds!

The Website's Memory

🛒 You add items to your basket and close the browser.

You come back later — they're still there!

How does the website remember?

Cookies! Small text files stored on YOUR computer.

Deep Dive: Cookie Types

Cookies Explained

Two Types of Cookies

Session Cookies

📝

Temporary — like a sticky note

Stored in RAM

Deleted when browser closes

Example: Shopping basket

Persistent Cookies

📓

Permanent — like a diary entry

Stored on Hard Drive

Remain until expiry or deleted

Example: "Remember Me" login

Connection to Topic 3

Remember RAM vs Hard Drive?

Session cookies = RAM (volatile, temporary)

Persistent cookies = Hard Drive (non-volatile, permanent)

This is why session cookies disappear when you close the browser!

RAM loses data when power is cut.

  2. "Session cookies are stored on your hard drive forever."
  3. "DNS converts an IP address into a URL."

Press Down for answers

Statement 1

"The Internet and the World Wide Web are the same thing."

❌ FALSE

The Internet is the physical infrastructure (cables, routers).

The WWW is a service that runs ON the Internet.

Statement 2

"Session cookies are stored on your hard drive forever."

❌ FALSE

Session cookies are stored in RAM (memory).

They're deleted when the browser closes.

Statement 3

"DNS converts an IP address into a URL."

❌ FALSE

It's the other way around!

DNS converts URL (human-readable) → IP address (machine-readable)

Statement 4

"HTTP is more secure than HTTPS."

❌ FALSE

HTTPS is secure (the 'S' stands for Secure!).

HTTP sends data in plain text — anyone can read it.
