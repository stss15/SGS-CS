## Unit overview
This unit helps you feel confident using your school MacBook and the main apps we use at St George's. You will learn how to handle the device safely, organize your files, and work in Word, PowerPoint, OneDrive, Teams, and OneNote. The goal is strong habits that make every future unit easier.

## Unit objectives
- Navigate the macOS interface (Finder, Dock, Launchpad, menu bar, file paths).
- Create and maintain an organized folder structure for schoolwork.
- Save, locate, and manage files using OneDrive and local storage.
- Use Teams as the hub for messages, assignments, and resources.
- Use OneNote Class Notebook (Content Library and personal section).
- Understand the difference between local and cloud storage.
- Work safely and respectfully in shared digital spaces.

## Core concepts
### Adaptation
How people and systems adjust to new tools and workflows.
In this unit: you adapt to the school's digital ecosystem and build new routines.

### Form
How information is organized and structured.
In this unit: you build clear folder structures and use sections and pages in OneNote.

### Function
The purpose of tools and systems.
In this unit: you learn why we use Teams, OneDrive, and OneNote.

## Skills developed
- Digital Literacy: using devices, apps, and settings safely.
- Data Handling: saving, naming, and organizing files.
- Creativity in Technology: choosing the right tool to present ideas.

## How to use this book
- Each chapter is one lesson.
- Read the keywords first, then the core content.
- Try the Quick check questions after each lesson.
- Use the Common pitfalls to avoid mistakes.
- If English is new to you, underline new words and ask your teacher for support.

## Quick start checklist
- Charge your MacBook and bring it to every lesson.
- Save all work to OneDrive.
- Use short, clear file names.
- Ask a teacher if you are unsure about a setting.
