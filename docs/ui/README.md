# UI

The UI target is a minimal academic editorial system: readable, quiet, and consistent across the whole site.

## Principles

- One shared shell language for the site chrome
- One token source for color, spacing, typography, and elevation
- One component vocabulary for cards, lists, pills, callsouts, and headers
- One typography system with limited, purposeful exceptions
- One accessibility baseline for contrast, focus, and mobile behavior

## Shells

- `CurriculumShell`: indexes, landing pages, and content hubs
- `ReaderShell`: textbooks and long-form reading
- `SlideShell`: slide decks and presentation-style content
- `ToolShell`: interactive tools, simulations, and app-like experiences

## Design Rules

- Default to left-aligned content-first layouts.
- Use warm neutrals with navy and gold accents.
- Avoid generic startup UI patterns and novelty-first decoration.
- Keep interactions obvious, keyboard-friendly, and classroom-safe.

See [design-system.md](design-system.md) for the component and token model.
