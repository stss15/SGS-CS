A1 Computer Fundamentals: Educator's Implementation Guide

This guide covers hardware operation, data representation, logic, and system software for Years 10–13. It includes specific Higher Level (HL) extensions for the IB curriculum.

A1.1: Computer Hardware & Operation

1. Key Terminology

Term Definition
ALUArithmetic Logic Unit: Performs calculations and logical comparisons.
CUControl Unit: Decodes instructions and manages the flow of data.
RegisterSmall, high-speed storage locations within the CPU (e.g., MAR, MDR, PC, IR, AC).
BusCommunication pathways (Address, Data, Control). Address/Data are typically bidirectional.

2. Knowledge & Skills

  • Fetch-Decode-Execute: Students must describe the movement of data between registers (e.g., PC content copied to MAR).
  • Multi-core vs. Co-processors: Differentiate between general-purpose cores and specialized co-processors like GPUs (parallel processing for matrix maths).
  • Memory Hierarchy: Rank primary memory (Registers > L1 Cache > L2 > L3 > RAM) by speed and size.

3. HL Extensions: Pipelining

  • Concept: Overlapping instruction stages to increase throughput.
  • Stages: Fetch, Decode, Execute, Memory Access, Write Back.

A1.2: Data Representation & Logic

1. Conversions (Skills)

  • Number Bases: Convert between Binary, Decimal, and Hexadecimal (up to 8-bit/2-digit hex).
  • Multimedia: Understand Sampling Rate (Hz) and Bit Depth (Quantization) for audio, and spatial/temporal compression for video.

2. Logic Gates & K-Maps

  • Karnaugh Maps (HL): Use Gray code headings (00, 01, 11, 10) to simplify Boolean expressions.

A1.3: Operating Systems & Control Systems (HL Expanded)

1. OS Management Functions

  • Memory Management: Using Virtual Memory (paging/segmentation) to swap data between RAM and Disk.
  • Scheduling Algorithms: FCFS, Round Robin (Time-slicing), and Priority (dealing with "Starvation").

2. HL Extension: The Control System Loop

For IB, students must move beyond definitions and explain the Process Flow:

  • Controllers (The Brain):
    • Logic: Receives a continuous signal from sensors representing the Actual State.
    • Comparison: It compares the Actual State against a Target State (Setpoint).
    • Algorithm: Executes a control algorithm (e.g., PID or simple threshold logic) to calculate the Error Signal.
    • Decision: Sends an electrical signal to actuators to reduce the error.
  • Actuators (The Muscles):
    • Transformation: Converts the low-power electrical control signal into physical work (kinetic, thermal, or fluid energy).
    • Examples for Slides:
      • Solenoid: Moving a deadbolt in a security system.
      • Relay: Switching a high-voltage heater on/off.
      • Stepper Motor: Precise limb movement in robotics.
  • Transducers: The broad category for any device that converts energy from one form to another (both sensors and actuators).

A1.4: Translation (HL)

  • Compilers vs. Interpreters: Focus on portability vs. execution speed.
  • JIT (Just-In-Time): How Java uses Bytecode for "hot spots" to optimize runtime.

Pedagogical Tips

  • Deadlock HL: Ensure students can explain the four conditions for deadlock (Mutual Exclusion, Hold and Wait, No Pre-emption, Circular Wait).
  • LMC Usage: Demonstrate the FDE cycle using the Little Man Computer instruction set (LDA, STA, ADD, etc.).
