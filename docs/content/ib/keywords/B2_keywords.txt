variable – A named memory location used to store a value that can change during execution.
data type – Classification that determines what values a variable can hold (e.g., integer, string).
integer – Whole number data type.
float – Decimal (real) number data type.
boolean – Data type with two values: true/false.
string – Sequence of characters (text).
operator – Symbol/keyword that performs an operation on operands (e.g., +, -, *, /, ==).
assignment – Storing a value in a variable (e.g., x = 5).
concatenation – Joining strings together (e.g., "Hi" + "!" → "Hi!").
type casting – Converting a value from one data type to another (e.g., int("5")).
input – Data provided to a program (user input, file input, sensors).
output – Data produced by a program (screen, file, network).
syntax error – Error caused by breaking language rules (detected before execution).
runtime error – Error that occurs while a program runs (e.g., divide by zero).
logic error – Program runs but produces incorrect results due to flawed reasoning.
debugging – Finding and fixing errors in code.
array/list – Data structure that stores multiple items under one identifier, accessed by index.
index – Position number used to access an element in an array/list (often starts at 0).
iteration – Repeating a block of code using loops.
selection – Choosing between paths using conditions (if/elif/else).
condition – Boolean expression that evaluates to true or false.
loop – Structure that repeats a set of instructions (for/while).
for loop – Loop that repeats over a known range/sequence.
while loop – Loop that repeats while a condition remains true.
function – Named block of reusable code that may return a value.
procedure – Named block of code that performs a task (often described as not returning a value).
parameter – Variable in a function definition that receives a value.
argument – Actual value passed into a function call.
return value – Value output from a function via return.
algorithm – Step-by-step method to solve a problem.
time complexity – How runtime grows as input size grows.
Big O notation – Notation describing the upper bound (worst-case growth) of time/space complexity.
linear search – Searching sequentially through items until found (O(n)).
binary search – Searching a sorted structure by halving the search space (O(log n)).
bubble sort – Simple comparison sort swapping adjacent items (O(n²)).
insertion sort – Builds a sorted list by inserting each item into the correct position (O(n²) average).
merge sort – Divide-and-conquer sort that merges sorted halves (O(n log n)).
stack – LIFO structure (last in, first out).
push – Add an item to the top of a stack.
pop – Remove the top item from a stack.
queue – FIFO structure (first in, first out).
enqueue – Add an item to the back of a queue.
dequeue – Remove an item from the front of a queue.
file – Stored collection of data on secondary storage.
record – Structured set of fields stored together (often one “row” of file data).
CSV – Comma-separated values file format for tabular data.
EOF – End of file marker/condition used when reading files.
