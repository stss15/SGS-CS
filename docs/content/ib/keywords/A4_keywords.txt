artificial intelligence (AI) – Computer systems able to perform tasks that normally require human intelligence (perception, reasoning, decision-making).
machine learning (ML) – Subset of AI where systems learn patterns from data to make predictions/decisions without explicit rules.
model – A learned mathematical representation that maps inputs to outputs.
training – Process of fitting a model to data so it learns patterns.
inference – Using a trained model to make predictions on new, unseen data.
training data – Data used to train a model (often split into training/validation/test sets).
label – The correct output in supervised learning (the “answer”).
feature – An input variable used by a model (e.g., age, temperature).
supervised learning – ML trained on labelled input–output pairs to generalize to new inputs.
regression – Supervised learning that predicts a continuous numerical value.
classification – Supervised learning that predicts a discrete category/class label.
unsupervised learning – ML on unlabelled data to discover structure or patterns (e.g., clusters, associations).
clustering – Unsupervised technique that groups data points based on similarity.
association rule learning – Unsupervised technique that finds relationships between items/attributes (e.g., market basket analysis).
reinforcement learning – ML where an agent learns actions by trial-and-error using rewards from an environment.
agent – The decision-maker in reinforcement learning.
environment – The world the agent interacts with; returns states and rewards.
reward – Feedback signal in reinforcement learning indicating how good an action was.
deep learning – ML approach that uses multi-layer neural networks to learn representations.
neural network – Model made of interconnected nodes (neurons) arranged in layers.
neuron (node) – Basic unit that combines inputs with weights and outputs an activation.
weight – Parameter controlling the strength of a connection in a neural network.
activation function – Function that introduces non-linearity in a neural network (e.g., ReLU, sigmoid).
transfer learning – Reusing a pre-trained model for a related task (fine-tuning instead of training from scratch).
generative AI – Models that generate new content (text, images, audio) based on learned patterns.
overfitting – When a model learns training data too well and performs poorly on new data.
underfitting – When a model is too simple to capture patterns and performs poorly even on training data.
hyperparameter – A setting chosen before training (e.g., learning rate, number of clusters).
hyperparameter tuning – Process of searching for hyperparameters that improve performance on validation data.
cross-validation – Evaluation method that tests performance across multiple train/validation splits.
metric – A numerical measure of model performance (e.g., accuracy, MSE).
data preprocessing – Preparing raw data for modelling (cleaning, selecting features, transforming).
data cleaning – Fixing issues like missing values, duplicates, incorrect formats, and outliers.
missing value – A field with no recorded data (null/blank) that may need handling.
outlier – A data point that deviates strongly from the typical pattern (may be error or rare case).
feature selection – Choosing the most useful input features to improve performance/efficiency.
dimensionality reduction – Reducing number of features while preserving useful structure (often via feature extraction).
PCA (principal component analysis) – Common dimensionality reduction technique that finds directions of maximum variance.
GPU (graphics processing unit) – Highly parallel processor used to accelerate matrix-heavy ML computations.
TPU (tensor processing unit) – Specialized hardware optimized for ML tensor operations.
NPU (neural processing unit) – Hardware accelerator designed for ML inference/training on-device.
edge device – Device that processes data locally near where it is generated (low latency, improved privacy).
cloud computing – On-demand remote computing resources (scalable CPUs/GPUs/TPUs) accessed over the internet.
data warehouse – Centralized analytics store used for reporting and business intelligence (often feeds ML).
algorithmic bias – Systematic unfairness caused by biased data, design choices, or deployment context.
fairness – Ethical goal that model outcomes do not discriminate unjustly against groups.
accountability – Who is responsible for decisions made with/through ML systems.
transparency – Ability to understand how a model was built and what data was used.
explainability – Ability to explain why a model produced a specific output.
privacy – Protection of personal information from misuse or unwanted exposure.
consent – Permission for data to be collected/used for a specific purpose.
surveillance – Monitoring people’s behaviour/data (often raising privacy and fairness concerns).
environmental impact – Energy use and carbon emissions from training and running ML systems.
deepfake – Synthetic media generated by AI that convincingly imitates real people/events.
