HL Stage 2

HL Stage 2: Python JSON practice

Keep this stage generic. The class should practice reading and writing JSON before touching the project backend.

Teacher onlyExact target state

Teacher objective

Run this as a low-risk Python lab

The examples here are deliberately not the project code. They are syntax practice that prepares students for the HL backend later.

Expected student output

  • Read a JSON file into Python.
  • Append a new object to a list.
  • Write the updated structure back to disk with indentation.

Questions and answers

Prompt for the class Expected answer / direction
Why practise on a generic file first? Because the project backend should not be the first time students have seen JSON file I/O.
What does json.load() return? A Python structure such as a list or dictionary based on the JSON file contents.
Why use indent=4 when writing? It keeps the file readable for humans.

read_inventory.py

PYTHON 
import json

with open("inventory.json") as f:
    items = json.load(f)

for item in items:
    print(item["name"], item["stock"])

Teaching notes for this file

  • Teach with open(...) and json.load() here.

update_inventory.py

PYTHON 
import json

new_item = {
    "name": "Glue sticks",
    "stock": 24,
    "location": "Cupboard B"
}

with open("inventory.json") as f:
    items = json.load(f)

items.append(new_item)

with open("inventory.json", "w") as f:
    json.dump(items, f, indent=4)

Teaching notes for this file

  • Teach append, then save back to disk with json.dump().
