Implementation step 4

Feature 4: Form inputs

This is where the interface catches up with the schema. Every input should map directly to planned data.

Teacher onlyExact target state

Teacher use on this page

Lesson focus, student target, and class answers

Use this as the teaching script for the live build. Start with the outcome, then use the build steps below to write the code in order.

What students should finish with

  • The modal contains title, user, priority, and due date controls.
  • Each control has a clear label and a stable identifier.
  • Students can explain which input maps to which field in storage.

Questions to ask and the answers you want

Prompt for the class Expected answer / direction
Why is the assignee control a select and not a plain text input? Because users already exist as stored records and the task should reference one of them.
Why is due date an input of type date? Because the browser can provide a date picker and the value is already structured correctly.
What do the input id values do? They let JavaScript read each value later when the form is submitted.

Form syntax

HTML and Bootstrap form terms to teach on this page

This is where students first meet the controls that later become request data.

HTML form elements

Element / attributeWhat it doesHow to explain it
<label>Names the purpose of an input.The user should not have to guess what a field means.
<input>Collects typed data.Good for text and date input.
<select>Presents fixed choices.Useful when the data should come from a limited set.
type="date"Uses the browser date input.This helps with consistent date entry.
id="..."Gives the element a unique name for JavaScript.The id becomes the bridge into the script later.
requiredStops empty form submission in the browser.Helpful for UI feedback, but not enough on its own.

Bootstrap form classes

ClassWhat it doesHow to explain it
form-labelStyles labels consistently.Use it so labels match the rest of the Bootstrap form design.
form-controlStyles text-like inputs.This gives inputs a standard readable shape.
form-selectStyles dropdown selects.This is the select version of form-control.
mb-3Adds spacing below a field group.Helps separate controls visually without custom CSS.

Live build order

Step-by-step code to write with the class

Write these blocks in order. Each block is smaller than the final file so the teacher can explain what is happening before moving on.

Step 1

Write this in templates/index.html

Add the task title input group

Start with the simplest text field and make the label-input relationship explicit.

                <div class="mb-3">
                    <label class="form-label">Task Title</label>
                    <input id="taskTitle" class="form-control">
                </div>

What this block does

  • label explains the field to the user.
  • id="taskTitle" is what JavaScript will later use to read the typed value.
Step 2

Write this in templates/index.html

Add assignee, priority, and due-date controls

These controls should map directly back to the planned database fields.

                <div class="mb-3">
                    <label class="form-label">Assign User</label>
                    <select id="taskUser" class="form-select"></select>
                </div>

                <div class="mb-3">
                    <label class="form-label">Priority</label>
                    <select id="taskPriority" class="form-select">
                        <option value="Low">Low</option>
                        <option value="Medium">Medium</option>
                        <option value="High">High</option>
                    </select>
                </div>

                <div class="mb-3">
                    <label class="form-label">Due Date</label>
                    <input type="date" id="taskDate" class="form-control">
                </div>

What this block does

  • The user select starts empty because JavaScript will populate it from the database.
  • Priority is a fixed set of choices, so a select is more appropriate than free text.
  • Due date uses a browser date input so students see that HTML can help with basic validation and format.

Watch for

Common mistakes to stop early

Teacher checks

  • Students giving the form controls different id names to the names the JavaScript will later use.
  • Using a text input for user instead of a select tied to existing records.
