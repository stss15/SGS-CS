abstract data type (ADT) – A data type defined by its operations/behaviour, not by its implementation.
abstraction – Hiding implementation details and exposing only essential features/operations.
interface – The set of operations a data structure provides (what you can do).
implementation – The internal way a data structure is built (how it works).
time complexity – How runtime grows as input size grows.
Big O notation – Notation describing the upper bound (worst-case growth) of time/space complexity.
O(1) – Constant time: runtime does not depend on input size.
O(log n) – Logarithmic time: runtime grows slowly as input size increases (common in balanced trees).
O(n) – Linear time: runtime grows proportionally with input size.
linked list – Collection of nodes where each node points to the next node.
node – A unit in a linked structure that stores data and one or more pointers.
pointer/reference – A value that refers to another node’s memory location.
head – Pointer/reference to the first node in a linked list.
tail – The final node in a linked list (often points to null).
singly linked list – Each node points to the next node only.
doubly linked list – Each node points to both the next and previous node.
circular linked list – The tail node points back to the head node.
traversal – Visiting nodes one-by-one by following pointers.
insertion – Adding a node to a linked structure.
deletion – Removing a node from a linked structure.
binary search tree (BST) – Tree where left subtree values are less than the node and right subtree values are greater.
tree – Hierarchical structure made of nodes connected by edges.
root – Top node of a tree.
parent – A node that has child nodes.
child – A node directly below a parent node.
leaf – A node with no children.
subtree – A node and its descendants considered as a tree.
balanced tree – Tree with height kept small so operations remain efficient.
set (ADT) – Collection of unique elements with no duplicates.
union – Set operation combining elements in either set.
intersection – Set operation returning elements common to both sets.
difference – Set operation returning elements in one set but not the other.
subset – Set A is a subset of B if every element of A is in B.
hash table – Key–value data structure that uses a hash function to map keys to indices.
hash function – Function that maps a key to an index (ideally evenly distributed).
collision – Two different keys map to the same index.
load factor – Measure of how full a hash table is (items ÷ table size).
rehashing – Resizing a hash table and re-inserting items to reduce collisions.
chaining – Collision resolution method using a list/collection at each index.
open addressing – Collision resolution method that finds another slot in the table when a collision occurs.
