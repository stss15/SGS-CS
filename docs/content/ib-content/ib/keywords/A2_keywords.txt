network – A set of connected devices that can communicate and share resources.
bandwidth – Maximum amount of data that can be transmitted per second over a link (e.g., Mbps).
latency – Delay between sending data and it arriving (often measured in ms).
PAN – Personal Area Network: very short-range network centred on an individual (e.g., Bluetooth).
LAN – Local Area Network: network over a small geographic area with low latency and high bandwidth.
WAN – Wide Area Network: network spanning large geographic areas, connecting multiple LANs.
VPN – Virtual Private Network: encrypted tunnel over a public network to create a secure private connection.
distributed system – Multiple networked computers (nodes) working together to provide a service.
fault tolerance – Ability of a system to keep working even when some components fail.
consistency – Property that all nodes see the same data/state, or changes are coordinated to avoid conflicts.
edge computing – Processing data near the source to reduce latency and bandwidth usage.
IoT – Internet of Things: networks of physical devices with sensors/actuators connected to the internet.
modem – Modulator–demodulator: converts between analogue signals (ISP links) and digital signals (local network).
router – Forwards packets between networks using IP addresses and routing tables.
IP address – Logical address used to identify a device on an IP network (Layer 3).
switch – Forwards frames within a LAN using MAC addresses, directing traffic to the correct port.
MAC address – Hardware address for a network interface, used for local delivery on a LAN (Layer 2).
gateway – Connects networks that use different protocols by translating between them (often at higher layers).
client–server – Model where clients request services/resources from a central server.
peer-to-peer (P2P) – Decentralised model where each node can act as both client and server.
TCP – Transmission Control Protocol: connection-oriented transport providing reliable, ordered delivery.
UDP – User Datagram Protocol: connectionless transport with low overhead and no built-in reliability.
segment – Transport-layer data unit (e.g., TCP segment).
packet – Internet-layer data unit containing an IP header and payload.
frame – Link-layer data unit containing a MAC header/trailer and payload.
encapsulation – Wrapping data with protocol headers (and sometimes trailers) as it moves down the network stack.
packet switching – Data is split into packets that are routed independently across the network.
MTU – Maximum Transmission Unit: the largest packet size a link can carry without fragmentation.
header – Metadata added to data (e.g., addresses, sequence numbers, checksums) to support delivery and processing.
sequence number – Field that identifies packet order so data can be reassembled correctly.
checksum – Value used to detect corruption in transmitted data.
subnet mask – Bitmask that separates the network portion and host portion of an IP address.
bitwise AND – Operation that outputs 1 only when both input bits are 1.
NAT – Network Address Translation: mapping private IP addresses to a public IP address to conserve IPv4 space.
DDoS – Distributed Denial of Service: overwhelming a target with traffic from many compromised sources.
botnet – Network of compromised devices controlled by an attacker (often used for DDoS).
SQL injection – Inserting malicious SQL into inputs to manipulate a database query.
MitM – Man-in-the-Middle attack: intercepting and potentially altering communication between two parties.
encryption – Transforming plaintext into ciphertext using a key so only authorised parties can recover it.
symmetric encryption – Uses the same secret key for encryption and decryption.
asymmetric encryption – Uses a public/private key pair (public encrypts, private decrypts).
digital certificate – Signed data that binds a public key to an identity (e.g., a domain).
CA – Certificate Authority: trusted organisation that issues/signs digital certificates.
Diffie–Hellman – Method for two parties to establish a shared secret over an insecure channel without sending the secret directly.
firewall – Security system that filters network traffic according to rules/policy.
packet filtering – Firewall approach that filters traffic based on header information (IP/ports/protocol).
stateful inspection – Firewall approach that tracks active connections and filters traffic based on connection state as well as headers.
