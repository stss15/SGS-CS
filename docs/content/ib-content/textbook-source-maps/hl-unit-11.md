## Unit Plan Extract (Context)
```text
Unit Plan: HL Unit 11 - Advanced Networking (A2.1, A2.2, A2.3, A2.4)
Subject: IB Computer Science (First Assessment 2027)
Grade: Year 13 (HL Only)
Duration: 5 Weeks (10 HL Lessons)
Theme: Theme A: Concepts of Computer Science
Unit Foundation
Concepts
The focus is on Architectural Abstraction and Proactive Defense. While SL covers the "what" of networks, HL investigates the "how"—specifically the orchestration of the TCP/IP Stack, the logic of Dynamic Routing, and the implementation of active countermeasures like IDS/IPS.
Content
	•	A2.1.5: The TCP/IP Model: Deep dive into the four layers (Application, Transport, Network, Data Link/Physical). Concepts of Encapsulation and Protocol Data Units (PDUs).
	•	A2.2.2: Advanced Server Types: Reverse Proxy (load balancing/security), Proxy Servers (anonymity/caching), and specialised Database/Web servers.
	•	A2.3.4: Dynamic Routing: Mechanics of routing tables, discovery protocols, and how routers determine the "optimal path" across complex, shifting networks.
	•	A2.4.2-3: Network Countermeasures: Differentiating between Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS). Identifying and mitigating sophisticated network threats.
Skills for Learning
	•	Thinking Skills: Evaluating the trade-offs between static and dynamic routing in enterprise environments.
	•	Communication Skills: Using the TCP/IP stack as a mental model to diagnose where communication failures occur (e.g., distinguishing between a DNS error and a hardware failure).
Approaches to Teaching
	•	Visualisation: Using "Packet Capture" tools (e.g., Wireshark) to physically see encapsulation headers added at each layer of the TCP/IP stack.
	•	Inquiry-based: Deduce the role of a Reverse Proxy by observing how high-traffic websites (like the airline booking scenario in the text) manage millions of requests.
	•	Simulation: Using network simulators to observe how dynamic routing tables update when a node is "disconnected" from the topology.
Terminology
TCP/IP Model, Encapsulation, PDU, Application Layer, Transport Layer, Network Layer, Data Link Layer, Reverse Proxy, Load Balancing, Dynamic Routing, Routing Table, Metric, IDS, IPS, False Positive/Negative.
Misconceptions
	•	Layer Confusion: Confusing the Network layer (IP addresses) with the Data Link layer (MAC addresses).
	•	IDS vs. IPS: Assuming an IDS can block traffic; students must understand that an IDS only alerts, while an IPS acts.
	•	Proxy Directions: Confusing a forward Proxy (protects the client) with a Reverse Proxy (protects the server).
	•	Routing Logic: Thinking routers always use the shortest physical path; they use the "optimal" path based on congestion, cost, or speed.
Adaptive Strategies
	•	Encapsulation Boxes: Use nested boxes (Russian dolls) to represent data being wrapped in headers as it moves down the stack.
	•	Routing Map Activity: Use a physical map of the classroom where students must find the "cheapest" path to a desk using specific "cost" markers on floor lines.
	•	ADHD-Aware Focus: Use the "Layer-by-Layer" diagnostic approach—solving network problems by starting at Layer 1 (Physical) and moving up.
TOK Connections
	•	Classification of Knowledge: Does the 4-layer TCP/IP model reflect the "truth" of electricity and light, or is it a human-made abstraction designed purely for utility?
	•	Expertise and Trust: How do digital certificates and SSL/TLS change our "belief" in the identity of a remote server?
IBO Learner Profile
	•	Inquirers: Investigating the underlying protocols that allow the internet to remain "self-healing" through dynamic routing.
	•	Principled: Understanding the ethical considerations of using IDS/IPS to monitor employee or user traffic.
```
