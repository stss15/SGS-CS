## Unit Plan Extract (Context)
```text
Unit Plan: SL Unit 4 - Algorithmic Control (B2.3, B2.4, B2.5)
Subject: IB Computer Science (First Assessment 2027)
Grade: Year 12 (SL)
Duration: 5 Weeks (14 Lessons)
Theme: Theme B: Computational Thinking and Problem-solving
Unit Foundation
Concepts
This unit moves from data storage to the mechanics of logic. It explores how programs make decisions (Selection), repeat tasks (Iteration), and organise logic into Modules. It also introduces the formal analysis of efficiency through Big O Notation and the necessity of Persistent Storage via File I/O.
Content
	•	B2.3: Sequencing, Selection (If/Elif/Else), and Looping (Count-controlled vs Conditional).
	•	B2.4: Algorithmic efficiency (Big O), Search algorithms (Linear, Binary), and Sort algorithms (Bubble, Selection).
	•	B2.5: File processing (Read, Write, Append) using Python’s native functions.
Skills for Learning
	•	Thinking Skills: Analysing the scalability of an algorithm. Calculating Big O to predict performance on large datasets.
	•	Research Skills: Evaluating the differences between sequential and random access in file processing.
Approaches to Teaching
	•	Incremental: Building from simple if statements to nested loops and complex sorting logic.
	•	Informed by Assessment: Frequent "dry run" tracing of sorting algorithms to ensure the logic of the "swap" is understood before coding.
	•	Contextualised: Using real-world datasets (e.g., student names in a text file) to demonstrate why searching and sorting are necessary.
Terminology
Selection, Iteration, Nested Loop, Modularization, Big O Notation, Time Complexity, Space Complexity, Linear Search, Binary Search, Bubble Sort, Selection Sort, Persistent Storage, Append Mode.
Misconceptions
	•	Binary Search: Students often forget that Binary Search requires a sorted list to function.
	•	Sorting Efficiency: Believing Bubble Sort is "good" because it's easy to write, without understanding its $O(n^2)$ limitation.
	•	File I/O: Forgetting to .close() a file or confusing 'w' (overwrite) with 'a' (append) modes.
	•	Loops: Infinite loops caused by incorrect termination conditions in while structures.
Adaptive Strategies
	•	Visual Learners: Use sorting animations or "human sorting" activities where students physically move to represent Bubble vs Selection sort.
	•	ADHD Awareness: Provide "Cheat Sheets" for SQL-like logic in Python selection and standard file opening patterns.
	•	Scaffolded Reasoning: Provide the outer loop of a sorting algorithm and ask students to complete the comparison and swap logic.
TOK Connections
	•	Reasoning and Decision-making: How does logical reasoning in code (Selection) mirror or differ from human decision-making? Does code "decide," or does it simply "follow"?
	•	The Value of Efficiency: Is a more efficient algorithm "better" if it is harder for a human to maintain and debug?
IBO Learner Profile
	•	Inquirers: Investigating why certain algorithms scale better than others.
	•	Principled: Understanding the importance of closing files and handling data responsibly.
CAS Connections
	•	Service: Creating a system to sort and manage a volunteer database for a local community centre.
```
