## Unit Plan Extract (Context)
```text
Unit Plan: HL Unit 8 - Supervised & Unsupervised (A4.3)
Subject: IB Computer Science (First Assessment 2027)
Grade: Year 13 (HL Only)
Duration: 2 Weeks (6 HL Lessons)
Theme: Theme A: Concepts of Computer Science
Unit Foundation
Concepts The unit focuses on Algorithmic Classification and Pattern Discovery. It explores the mechanics of Supervised Learning (predicting labels) and Unsupervised Learning (discovering structure). Key themes include Proximity-based Logic, Entropy-driven Decisions, and Optimization through parameter refinement.
Content - A4.3.4: Supervised Learning Models: K-Nearest Neighbours (K-NN) (distance metrics) and Decision Trees (splitting criteria).
	•	A4.3.5: Model Optimization: Hyperparameter tuning (k-value in K-NN, depth in trees) to balance bias and variance.
	•	A4.3.6: Unsupervised Learning: Clustering (grouping similar data points without labels).
	•	A4.3.7: Association Rule Mining: Discovering relationships between variables (e.g., Market Basket Analysis).
Skills for Learning - Thinking Skills: Evaluating model performance and identifying when a model is underfitting or overfitting.
	•	Research Skills: Investigating real-world applications of association rules in e-commerce and retail.
Approaches to Teaching - Inquiry-based: Using "Market Basket" datasets to deduce purchasing patterns before introducing formal association rules.
	•	Visualisation: Plotting 2D data to manually "cluster" points before applying an algorithm.
	•	Problem-based: Adjusting the 'k' value in a K-NN simulation to observe changes in classification boundaries.
Terminology K-Nearest Neighbours (K-NN), Decision Tree, Entropy, Information Gain, Hyperparameter, Tuning, Clustering, K-Means, Association Rule Mining, Support, Confidence, Lift, Overfitting, Underfitting.
Misconceptions - K-NN Simplicity: Believing K-NN is always efficient; ignoring the computational cost of distance calculations in high-dimensional space.
	•	Clustering vs Classification: Confusing unsupervised grouping (Clustering) with supervised labelling (Classification).
	•	Correlation as Causality: In association rule mining, assuming that because items A and B are bought together, A causes the purchase of B.
Adaptive Strategies - Visual Branching: Use physical flowchart cards to build a "Human Decision Tree" for a simple classification task (e.g., identifying a fruit).
	•	Distance Mapping: Use string and a physical grid to demonstrate how K-NN selects neighbours based on Euclidean distance.
	•	ADHD-Aware Checkpoints: Divide model tuning into discrete steps: 1. Baseline result, 2. Parameter change, 3. Re-test, 4. Comparison.
TOK Connections - The Ethics of Classification: When an algorithm classifies a person (e.g., credit risk), does the mathematical "label" become a new form of truth that overrides individual nuance?
	•	Knowledge in Patterns: Does finding a pattern in a cluster mean we have gained "knowledge," or have we simply identified a statistical coincidence?
IBO Learner Profile - Thinkers: Critically analyzing the "Lift" and "Confidence" of association rules to make business or scientific decisions.
	•	Open-minded: Recognizing that unsupervised learning can reveal structures in data that human bias might have overlooked.
CAS Connections - Service: Using clustering techniques to help a local community group or school department identify patterns in their resource usage or event attendance.
```
