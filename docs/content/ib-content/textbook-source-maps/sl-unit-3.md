## Unit Plan Extract (Context)
```text
Unit Plan: SL Unit 3 - Data Structures & Logic (B2.2)
Subject: IB Computer Science (First Assessment 2027)
Grade: Year 12 (SL)
Duration: 3 Weeks (9 Lessons)
Theme: Theme B: Computational Thinking and Problem-solving
Unit Foundation
Concepts
The transition from single-item variables to collections. This unit explores how data is organised to improve efficiency in both time (speed of access) and space (memory usage). Key concepts include Contiguous vs Non-contiguous memory, LIFO/FIFO protocols, and Direct vs Sequential access.
Content
	•	B2.2.1: Comparing static (fixed-size, contiguous) vs dynamic (resizable, non-contiguous) data structures.
	•	B2.2.2: Implementation and traversal of 1D and 2D lists (arrays).
	•	B2.2.3: The Stack ADT: LIFO principle, operations (push, pop, peek, isEmpty).
	•	B2.2.4: The Queue ADT: FIFO principle, operations (enqueue, dequeue, front, isEmpty).
Skills for Learning
	•	Thinking Skills: Evaluating which data structure is most appropriate for a given real-world scenario.
	•	Communication Skills: Using diagrams (sketches) to represent the state of a stack or queue after specific operations.
Approaches to Teaching
	•	Inquiry-based: Using physical objects (piles of coins, lines of people) to deduce LIFO/FIFO logic.
	•	Collaborative: Group "Matrix" challenges for 2D list manipulation.
	•	Conceptual: Linking stack usage to real-world software features like "Undo" and "Back" buttons.
Terminology
Static, Dynamic, Contiguous, Direct Access, Sequential Access, Pointer, LIFO, FIFO, Push, Pop, Peek, Enqueue, Dequeue, Underflow, Overflow, Matrix, Principal Diagonal.
Misconceptions
	•	Direct Access: Students often try to "directly access" an element in a dynamic list using an index without realising that under the hood, some structures require sequential traversal.
	•	Static Size: Believing a static array can be resized if it gets "full."
	•	Stack/Queue Logic: Mixing up the end where data is added (e.g., trying to pop from the bottom of a stack).
	•	2D Indices: Confusing [row][column] order (remember: "RC Cola" or "Rows then Columns").
Adaptive Strategies
	•	Kinesthetic Learners: Use a physical "human queue" or "stack of trays" to demonstrate pointer movement (Front/Rear/TopIndex).
	•	Scaffolded Code: Provide "starter" code for 2D list traversal where students only write the logic for the inner loop.
	•	Visual Aids: Use colour-coded grids to represent 2D lists to help students visualise nested loop iterations.
TOK Connections
	•	Classification as Knowledge: How does the way we "structure" data change what we can know about it? (e.g., searching a sorted list vs an unsorted one).
	•	Efficiency vs Truth: Is an "optimal" algorithm more valuable than one that is easier for humans to understand?
IBO Learner Profile
	•	Knowledgeable: Understanding the underlying memory mechanics of the data structures used in modern Python.
	•	Thinkers: Critically comparing the advantages/disadvantages of static vs dynamic structures.
CAS Connections
	•	Activity: Organising the "logic" of a sports tournament (Queue for matches) or a library return system (Stack).
```
