# Migration Phases

## Phase 1

Consolidate the shared shell, navigation, breadcrumbs, page widths, and tokens.

## Phase 2

Move curriculum indexes, reader flows, textbooks, and unit plans into a consistent typed content structure.

## Phase 3

Normalize assessments, flashcards, and any other data-driven classroom experiences.

## Phase 4

Normalize slide decks around one shell and one slide authoring contract.

## Phase 5

Move tools and simulations into a small set of reusable runtime patterns, using React islands only where the interaction complexity justifies it.

## Phase 6

Make downloadables and printables manifest-backed first-class assets.

## Phase 7

Remove legacy Nunjucks rendering and bridge scripts only when parity checks prove they are no longer needed.
