# Assessments (IGCSE)

## Current Structure

- Assessment menus live in `src/static/igcse/topic*/assessments.html`.
- Assessment question pages live in `src/static/igcse/topic*/**/*_assessment.html`.
- Assessment pages now use the shared runtime + JSON data (legacy per-page JS removed).
- End-of-unit tests now use shared runtimes + JSON data: auto-graded topics use `src/static/js/assessment-runtime.js`, and the exam-style Topic 4 uses `src/static/js/exam-runtime.js`.
- Shared assessment runtime: `src/static/js/assessment-runtime.js`.
- Shared exam runtime: `src/static/js/exam-runtime.js`.
- Assessment JSON data lives under `src/static/data/assessments/`.
- Assessment pages reference JSON via `data-assessment-json` on `<body>`.
- Assessment page styling is split between:
  - `src/static/css/assessment-base.css` (question pages).
  - `src/static/css/assessments-igcse-menu.css` (menu pages, with body variants).

## Proposed Data Schema (Draft)

Move question content into JSON data so the runtime logic can be shared.

```json
{
  "id": "topic1-1-1",
  "title": "1.1 Number Systems",
  "questions": [
    {
      "id": "q1",
      "type": "match",
      "title": "Terminology Match",
      "defs": [{ "id": "1", "text": "Single 0 or 1" }],
      "terms": [{ "id": "1", "text": "Bit" }]
    },
    {
      "id": "q7",
      "type": "mcq",
      "title": "Binary Addition",
      "options": [
        { "text": "10100000", "correct": true }
      ]
    }
  ]
}
```

Notes:
- Keep `questionMeta` equivalent fields (`id`, `title`, `type`) in data.
- Normalize `trueFalse` vs `tf` into a single type to reduce branching.
- Type-specific payloads (`defs`/`terms`, `options`, `statements`, `order`) should live alongside each question.

## Runtime

- Include `/js/assessment-runtime.js` after the assessment markup.
- Set `data-assessment-json="/data/assessments/..."` on `<body>` to point at JSON data.
- Supported types: `match`, `order`, `mcq`, `drag`, `dropdown`, `trueFalse`/`tf`, `sortable`, `numeric`.
- Drag questions can optionally define `expectedRemaining` to allow distractors left in the source list.
- Manual-response exams should include `/js/exam-runtime.js` and set `data-exam-json="/data/assessments/..."` for PDF metadata.

## Migration Plan (Draft)

1. Build a shared runtime (`js/assessment-runtime.js`) that renders questions from JSON.
2. Migrate all assessment pages to the shared runtime + JSON data (completed for every `igcse/topic*/**/*_assessment.html`).
3. Remove legacy per-assessment JS once all assessments are migrated (completed for assessment pages).
4. Migrate end-of-unit tests to shared runtimes and remove their legacy scripts (completed for topics 2-10).
5. Create a shared exam runtime for manual-response tests and wire Topic 4 to it (completed).
