This appendix is a quick reference for the most useful commands and rules from Unit 1. Use it when you need a fast reminder.

## Learning goals
- Recall key shortcuts and commands.
- Choose the correct app and tool quickly.
- Solve common problems with simple steps.

## Lesson 1.8.1: Shortcut Card and Quick Commands
### Keywords
- Shortcut: A key combination that saves time.
- Modifier key: Command, Option, Control, or Shift.
- Quick command: A tool you use often.

### Core content
Core shortcuts:
- Cmd+C = Copy
- Cmd+V = Paste
- Cmd+S = Save
- Cmd+Z = Undo
- Cmd+Shift+3 = Full screen screenshot
- Cmd+Shift+4 = Selection screenshot
- Cmd+Tab = Switch apps
- Cmd+Q = Quit app
Modifiers:
- Command (Cmd) is the main shortcut key.
- Shift makes letters uppercase or adds a new action.

### Key reminders
- Practice a few shortcuts each week until they feel automatic.

### Try it
- Create a small printed card or digital note with your top five shortcuts.

### Quick check
1. What does Cmd+V do?
2. Which shortcut quits an app?
3. Which shortcut takes a selection screenshot?

## Lesson 1.8.2: When to Use What - Application Guide
### Keywords
- Decision tree: A guide that helps you choose.
- Word vs PowerPoint: Choosing the right app.
- Email vs Teams: Choosing the right communication tool.
- OneDrive vs On My Mac: Choosing the right storage.

### Core content
- If you are writing paragraphs, use Word.
- If you are presenting slides, use PowerPoint.
- If you are messaging a teacher formally, use Email.
- If you are chatting quickly with classmates, use Teams.
- If you want your work backed up, save to OneDrive.
- Avoid saving important work to On My Mac.

### Key reminders
- The right tool makes work faster and clearer.

### Try it
- Choose the correct tool for three different tasks.

### Quick check
1. Which tool is best for a presentation?
2. Which tool is best for a formal message to a teacher?
3. Where should you save all school work?

## Lesson 1.8.3: Troubleshooting Common Issues
### Keywords
- Frozen: An app that is not responding.
- Search: Using Finder to locate files.
- Sync error: A problem syncing to the cloud.
- Force Quit: Closing an unresponsive app.

### Core content
If an app is frozen, wait 10 seconds. If it still does not respond, use Cmd+Option+Esc to open Force Quit, then close the app.
If a file is missing, use Finder search and check OneDrive. If OneNote shows a sync error, tell your teacher.
If the MacBook will not turn on, check the charger, then press and hold the power button for a few seconds.

### Key reminders
- Force Quit is a last resort, not a normal exit.
- Ask for help if you are unsure.

### Try it
- Describe the steps for a frozen app.
- List where you would search for a missing file.

### Quick check
1. What shortcut opens Force Quit?
2. What should you do if OneNote shows a sync error?
3. What is the first thing to check if the MacBook will not turn on?

## Lesson 1.8.4: Digital Citizenship and Computer Care
### Keywords
- Digital citizenship: Safe and respectful behavior online.
- Computer care: Keeping your device clean and safe.
- Safety: Protecting yourself and others.

### Core content
Be kind online and use school tools for school work. Report any uncomfortable content or messages to a teacher.
Keep food and drinks away from your MacBook. Close the lid gently, carry it with two hands, and clean the screen with a soft cloth only.

### Key reminders
- Respect others online and in shared spaces.
- Protect your device so it lasts.

### Try it
- Write two rules for safe online behavior.
- List two ways to protect your MacBook.

### Quick check
1. What should you do if you see uncomfortable content?
2. Why should you keep drinks away from your MacBook?
3. What is one way to clean the screen safely?
