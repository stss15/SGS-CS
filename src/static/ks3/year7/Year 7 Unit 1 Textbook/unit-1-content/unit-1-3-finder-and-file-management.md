## Topic summary
This topic shows you how to find, organize, and manage files. You will use Finder, follow the OneDrive rule, and keep your folders tidy.

## Learning goals
- Use Finder to locate files and folders.
- Save work in OneDrive and check sync status.
- Create folders with clear names and structure.
- Move, copy, search, and delete files safely.

## Lesson 1.3.1: Understanding Finder and the Desktop
### Keywords
- Finder: The app that helps you find files and folders.
- Desktop: The main screen area where icons appear.
- Dock: The row of app icons at the bottom of the screen.
- Menu bar: The bar at the top that changes for each app.

### Core content
Finder is the file browser on a Mac. It is the blue smiley face icon in the Dock. Use Finder to open folders, move files, and search for work.
The Desktop is a workspace, not a storage place. Use it for temporary files only, then move them into folders.
The menu bar changes based on the app you are using. The Dock helps you open apps and see which ones are running.

### Key reminders
- Keep the Desktop clean.
- Check the menu bar to see which app is active.

### Try it
- Open Finder and look at the sidebar, toolbar, and search bar.
- Move one file from the Desktop into a folder.

### Quick check
1. What is Finder used for?
2. Why should the Desktop stay clean?
3. Where do you find the menu bar?

### Did you know
Finder has been part of macOS since 1984.

### Common pitfalls
- Using the Desktop as permanent storage.
- Looking for app settings in the wrong menu bar.

### Exam tip
Finder is the file browser on a Mac.

## Lesson 1.3.2: The OneDrive Rule and Cloud Storage
### Keywords
- OneDrive: The school cloud storage space.
- Cloud storage: Files stored online and synced to devices.
- Sync: When files update between your MacBook and the cloud.
- Local storage: Files stored only on your MacBook.

### Core content
The OneDrive rule is simple: save everything to OneDrive. Cloud storage keeps your work safe and available on any device. Local storage ("On My Mac") is not backed up.
Look for status icons. A green check means the file is synced. Spinning arrows mean syncing. A red X means an error. If you see a red X, tell your teacher.

### Key reminders
- Check for a green check before closing your MacBook.
- Use OneDrive for all school files.

### Try it
- Save a document to your OneDrive folder.
- Find the sync status icon and explain what it means.

### Quick check
1. Why should you save to OneDrive?
2. What does a green check mean?
3. What should you do if you see a red X?

### Did you know
Your files are stored in secure data centers and can be opened on any device with your school login.

### Common pitfalls
- Saving work to "On My Mac" instead of OneDrive.

### Exam tip
OneDrive keeps files backed up and accessible anywhere.

## Lesson 1.3.3: Creating and Naming Folders
### Keywords
- Folder: A place to organize files.
- Naming convention: A clear, consistent way to name files and folders.
- Hierarchy: A folder structure with levels (Year, Subject, Topic).

### Core content
Create a new folder by right clicking (two-finger tap) and choosing New Folder. Name it immediately. Use clear names like "English_Essay" or "Science_Projects". Avoid special characters like / \ : * ? " < > | because they break file paths.
Build a simple hierarchy: Year7 > Subject > Topic. This makes it easy to find your work later.

### Key reminders
- Name folders right away.
- Keep names short, clear, and consistent.

### Try it
- Create a Year7 folder, then add two subject folders.
- Rename a folder by clicking its name once, then again.

### Quick check
1. Which characters should you avoid in file names?
2. Why is a folder hierarchy helpful?
3. How do you rename a folder?

### Did you know
The folder icon is based on a real paper folder used in offices.

### Common pitfalls
- Leaving folders named "Untitled".
- Using symbols that break file names.

### Exam tip
A valid name uses letters, numbers, and underscores.

## Lesson 1.3.4: File Operations and Navigation
### Keywords
- Double click: Two quick clicks to open a file or folder.
- Drag: Click and move a file to a new place.
- Search: Find files by typing in the Finder search bar.
- Quick Look: Preview a file by pressing the space bar.

### Core content
Double click a file to open it. Drag files to move them between folders. Use copy and paste to duplicate a file when you need a second copy.
Quick Look lets you preview a file without opening it. Press the space bar to open Quick Look, then press it again to close. Use the Finder search bar to find files quickly.

### Key reminders
- Use Search when you cannot find a file.
- Quick Look saves time.

### Try it
- Preview a file with Quick Look.
- Move a file to a new folder using drag and drop.

### Quick check
1. How do you preview a file without opening it?
2. What is the search bar used for?
3. What is the difference between move and copy?

### Did you know
Typing a few letters in Finder highlights the first matching file.

### Common pitfalls
- Creating duplicates by copying instead of moving.

### Exam tip
Press the space bar for Quick Look.

## Lesson 1.3.5: Trash and File Deletion
### Keywords
- Trash: The place where deleted files go first.
- Delete: Remove a file.
- Empty Trash: Permanently delete files.
- Permanent deletion: Files are gone and cannot be recovered easily.

### Core content
To delete a file, drag it to the Trash or press Cmd+Delete. The file stays in the Trash until you empty it. You can restore files from the Trash before emptying.
Empty the Trash to free storage space. Always check the Trash before you empty it to avoid deleting important work.

### Key reminders
- Trash is not permanent until you empty it.
- Check before you empty the Trash.

### Try it
- Move a test file to the Trash, then restore it.
- Empty the Trash with teacher permission.

### Quick check
1. Where do deleted files go first?
2. How do you permanently delete files?
3. Why should you check the Trash before emptying?

### Did you know
Files in the Trash still use storage space.

### Common pitfalls
- Forgetting to empty the Trash.
- Emptying without checking.

### Exam tip
Emptying the Trash is the permanent delete step.
