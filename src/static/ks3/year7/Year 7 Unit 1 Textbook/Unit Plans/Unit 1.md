### 1.1.3 Keyboard & Shortcuts

**Keywords:** Home Row (ASDF JKL;) • Command key (main shortcut key)

![SVG: Keyboard diagram highlighting home row keys and modifier keys](placeholder-keyboard-layout.svg)

**Home Row:** Fingers rest on ASDF and JKL; — Feel the bumps on F and J

| Key | Symbol | What it does |
|-----|--------|--------------|
| Command | ⌘ | Shortcuts (like Ctrl on PC) |
| Option | ⌥ | Extra characters |
| Control | ⌃ | Menu shortcuts |
| Delete | ⌫ | Erase backward |
| Return | ↵ | New line / Confirm |

**Essential Shortcuts:**

| Shortcut | Action |
|----------|--------|
| ⌘ + C | Copy |
| ⌘ + V | Paste |
| ⌘ + Z | Undo |
| ⌘ + S | Save |
| ⌘ + Q | Quit app |

#### **1.2.5 Clipboard & Undo**

**Keywords:** Clipboard (temporary storage) • Undo (⌘Z)

![SVG: Copy → Clipboard → Paste flowchart](placeholder-clipboard.svg)

| Concept | What happens |
|---------|-------------|
| Copy (⌘C) | Item goes to clipboard |
| Paste (⌘V) | Clipboard → current location |
| New copy | Replaces old clipboard |
| Undo (⌘Z) | Reverses last action |
| Redo (⌘⇧Z) | Reverses an undo |

Warning: Clipboard holds **one item** – paste before copying again!

|--------|-------|--------|

| Yellow | Yellow | Minimize to Dock |
| Green | Green | Full screen |

Warning: Red button ≠ Quit! Check for dot under Dock icon

#### **1.4.3 Quit vs Close**

**Keywords:** Quit (⌘Q) • Close (red button) • Dot (app running)

![SVG: Dock showing dots under running apps](placeholder-dock-dots.svg)

| Action | How | Result |
|--------|-----|--------|
| Close | Red button | Window gone, app may run |
| Quit | ⌘ + Q | App fully closed |

**The dot test:** Dot under icon = app still running

Tip: Quit unused apps to speed up your MacBook

### **Unit Summary**

**What You've Learned:**
- **Physical Skills:** How to safely handle and operate your MacBook, including trackpad gestures, keyboard shortcuts, and power management
- **File Management:** The OneDrive Rule, creating organized folder structures, and understanding cloud vs local storage
- **Application Skills:** Opening and managing apps, controlling windows, and choosing between Word and PowerPoint
- **Communication:** Writing clear emails with proper structure, managing your inbox, and knowing when to use Teams vs email
- **Organization:** Navigating OneNote's five sections, understanding sync status, and collaborating responsibly

**Key Habits to Maintain:**
1. **Always save to OneDrive** - never "On My Mac"
2. **Check sync status** before closing OneNote or shutting down
3. **Use descriptive file names** with Subject_Topic format
4. **Master the five core shortcuts** (⌘C, ⌘V, ⌘S, ⌘⇧3, ⌘Z)
5. **Keep your Desktop clean** and inbox organized

**Looking Ahead:**
These foundational skills will be used in every future Computer Science unit. Practice them until they become automatic—good digital habits now will save you hours of frustration later.
