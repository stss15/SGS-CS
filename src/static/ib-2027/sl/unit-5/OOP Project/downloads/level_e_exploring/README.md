# Level E: Mission Log + Exploration

This level adds a small OOP task while you explore the full station.

## Part A: Logbook Micro-Lab (Aggregation)
1. Create `student/logbook.py` with a Logbook class
2. Add `attach_logbook()` and `record_event()` to Player
3. Run `python3 validate.py`
4. Run `python3 run_lab.py` to see your log in action

## Part B: Explore the Station
1. Run `python3 run_game.py` and explore all 10 rooms
2. Open the engine files and answer the worksheet questions
3. Discuss with a partner

Note: Encounters can trigger while you explore. The engine prints the combat options; just enter a number to choose.

## Files to Read
- `engine/content/rooms.json`
- `engine/world_loader.py`
- `engine/command_parser.py`
