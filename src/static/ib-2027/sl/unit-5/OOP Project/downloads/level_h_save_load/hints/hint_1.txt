=== HINT 1: Understanding Serialization ===

GOAL:
Save and load the player's state to/from a file.
The game engine handles the file, but YOU handle 
converting your Player to data and back.

WHAT IS SERIALIZATION?
  - Converting an object to data (dictionary/JSON)
  - So it can be saved to a file
  - Then later recreated exactly

TWO METHODS NEEDED:

1. to_save_data()
   - Returns a dictionary with all player info
   - Called when saving

2. from_save_data(data) - CLASS METHOD
   - Takes a dictionary
   - Returns a new Player with that data
   - Called when loading
