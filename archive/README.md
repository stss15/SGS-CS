# Archive Directory

## Contents

### docs-txt/
Source text files used to generate content:
- `ks3/` - KS3 unit plans and lesson content

## Why Archived?

These files served as source material for building the site content. The content has been incorporated into the actual pages/templates, so these text files are no longer needed for the build process but are preserved for historical reference.
