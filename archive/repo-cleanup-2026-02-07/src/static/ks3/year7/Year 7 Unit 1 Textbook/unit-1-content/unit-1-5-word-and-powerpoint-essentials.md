## Topic summary
This topic helps you choose the right Office app and use it well. You will learn Word and PowerPoint basics, clear formatting, saving with AutoSave, and sharing work with teachers.

## Learning goals
- Choose Word or PowerPoint for the task.
- Format text clearly in Word.
- Create and organize slides in PowerPoint.
- Save work to OneDrive with AutoSave on.
- Share files with the right permission.

## Lesson 1.5.1: Choosing the Right Application
### Keywords
- Word: App for writing documents.
- PowerPoint: App for slide presentations.
- Document: A multi-page text file.
- Presentation: A set of slides.

### Core content
Use Word for essays, reports, letters, and any work with paragraphs. Use PowerPoint for slides, talks, and visual presentations.
Excel is for tables and charts, but we will focus on Word and PowerPoint in this unit. Teams is for communication, not for creating documents.

### Key reminders
- Paragraphs and reports go in Word.
- Slides and talks go in PowerPoint.

### Try it
- Decide which app you would use for a book report.
- Decide which app you would use for a class presentation.

### Quick check
1. Which app is best for a multi-page essay?
2. Which app is best for slides?
3. Is Teams used to create documents?

### Did you know
Microsoft Word was originally called Multi-Tool Word when it launched in 1983.

### Common pitfalls
- Using PowerPoint for essays.

### Exam tip
Word is for multi-page text documents.

## Lesson 1.5.2: Word Basics and Core Formatting
### Keywords
- Font: The style of text.
- Font size: How large the text is.
- Bold: Darker, thicker text.
- Italic: Slanted text.
- Underline: A line under text.
- Alignment: Where text sits on the page (left, center, right).

### Core content
In Word, the Home tab has the main formatting tools. Select text first, then apply Bold, Italic, or Underline. Use size 12 for normal writing and a larger size for headings.
Keep your formatting consistent. Use one or two fonts only, and align body text to the left for easy reading.

### Key reminders
- Select text before you format it.
- Keep fonts and sizes consistent.

### Try it
- Type a short paragraph and make the title bold.
- Change the font size of a heading to 16.

### Quick check
1. Where do you find the Bold button?
2. What is a good font size for body text?
3. Which alignment is best for normal paragraphs?

### Did you know
The default Word font is Calibri, designed for clear on-screen reading.

### Common pitfalls
- Formatting before selecting text.
- Using too many fonts.

### Exam tip
The Bold button is on the Home tab.

## Lesson 1.5.3: PowerPoint Basics and Slide Management
### Keywords
- Slide: One page of a presentation.
- Thumbnail pane: The list of slides on the left.
- Layout: The design of a slide.
- New Slide: The button to add a slide.

### Core content
PowerPoint has three main areas: the thumbnail pane on the left, the slide editor in the middle, and the ribbon at the top. Click New Slide to add a slide and choose a layout.
Use layouts to keep your slides consistent. Keep text large so the class can read it from a distance.

### Key reminders
- Use slide titles on every slide.
- Use large fonts for readability.

### Try it
- Create three slides with different layouts.
- Reorder slides by dragging in the thumbnail pane.

### Quick check
1. Which pane shows all slides?
2. Where do you add a new slide?
3. Why should slide text be large?

### Did you know
PowerPoint was first made for the Mac and was originally called Presenter.

### Common pitfalls
- Using tiny fonts on slides.

### Exam tip
The thumbnail pane shows all slides.

## Lesson 1.5.4: Saving and AutoSave in OneDrive
### Keywords
- AutoSave: Automatic saving while you work.
- OneDrive: School cloud storage.
- Cloud: Online storage.
- Save As: Save a new copy with a new name or location.

### Core content
AutoSave works only when your file is in OneDrive. Check the AutoSave toggle in the top bar and make sure it is on. Look for the word "Saved" to confirm.
If a file is saved on the Desktop or "On My Mac", AutoSave will not work. Use Save As to move it into OneDrive. Use Cmd+S to save manually as a backup.

### Key reminders
- AutoSave only works in OneDrive.
- Always check for the "Saved" status.

### Try it
- Turn AutoSave on and confirm the Saved status.
- Use Save As to move a file into OneDrive.

### Quick check
1. When does AutoSave work?
2. What should you do if AutoSave is off?
3. Which shortcut saves manually?

### Did you know
AutoSave can save your work every few seconds, so you lose less if the battery runs out.

### Common pitfalls
- Saving to the Desktop and losing AutoSave.

### Exam tip
AutoSave works only when the file is stored in OneDrive.

## Lesson 1.5.5: Sharing Files with Teachers
### Keywords
- Share: Send a file to another person.
- Permission: What the other person can do.
- Can Edit: The person can comment or change the file.
- Can View: The person can only read the file.

### Core content
Use the Share button in Word or PowerPoint. Type your teacher's email, choose the correct permission, and add a short message.
Name your file clearly before sharing so your teacher can find it. Check that the share link is correct before you close the file.

### Key reminders
- Use Can Edit when your teacher needs to comment.
- Check the file name before you share.

### Try it
- Practice sharing a file with a classmate using Can View.
- Change the permission to Can Edit and explain the difference.

### Quick check
1. Where is the Share button?
2. Which permission lets a teacher comment?
3. Why should you name a file before sharing?

### Did you know
Teachers can leave comments inside your document when they have edit access.

### Common pitfalls
- Forgetting to share after finishing the work.
- Choosing the wrong permission.

### Exam tip
Can Edit allows comments and changes.
