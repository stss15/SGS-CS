=== HINT 3: Method Checklist ===

Make sure your method:
- Takes ONLY `options` as the parameter
- Uses input() to read the user's choice
- Converts input to an integer and subtracts 1
- Validates range and repeats until valid
- Returns the 0-based index (0, 1, 2, ...)

Common mistakes to avoid:
- Printing the options (the engine already did)
- Returning the option text instead of the index
- Forgetting to handle non-numeric input

Run validate.py to check your work!
