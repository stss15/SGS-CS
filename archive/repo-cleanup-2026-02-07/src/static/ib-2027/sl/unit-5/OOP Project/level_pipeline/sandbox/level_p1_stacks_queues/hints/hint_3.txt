=== HINT 3: The Queue Class ===

KEY DIFFERENCE FROM STACK:
  - Stack: add to end, remove from END (LIFO)
  - Queue: add to end, remove from FRONT (FIFO)

RECOMMENDED: Use collections.deque for efficiency
  - Import deque from collections

STRUCTURE (in words):
  - __init__: create an empty deque called _items
  - enqueue: add item to the back (right side)
  - dequeue: if empty return None; otherwise remove and return the front item
  - front: if empty return None; otherwise return front item without removing
  - is_empty: same pattern as Stack
  - size: same pattern as Stack

---------------------------------------------
WHY DEQUE?
---------------------------------------------
  - Normal list.pop(0) is SLOW (O(n))
  - deque.popleft() is FAST (O(1))
  - For queues, you need fast removal from front

---------------------------------------------
WHY FIFO?
---------------------------------------------
  enqueue(A), enqueue(B), enqueue(C)
  deque is now: [A, B, C]
  
  dequeue() returns A  (first in, first out)
  deque is now: [B, C]
