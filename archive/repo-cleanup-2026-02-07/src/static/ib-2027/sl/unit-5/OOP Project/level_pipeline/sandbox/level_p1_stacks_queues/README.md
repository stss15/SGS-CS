# Level P1: Terminal Access

The Control Hub terminal is locked. You need to implement Stack and Queue data structures to bypass the security.

## Instructions
1. Open `student/data_structs.py`
2. Implement `Stack` using a Python list (LIFO)
3. Implement `Queue` using `collections.deque` (FIFO)
4. Run `python3 validate.py` to check your logic
5. Run `python3 run_puzzle.py` to hack the terminal!
