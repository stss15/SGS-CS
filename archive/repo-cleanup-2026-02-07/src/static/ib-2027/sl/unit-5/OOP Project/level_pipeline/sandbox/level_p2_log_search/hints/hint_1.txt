=== HINT 1: Understanding the Task ===

GOAL:
Create functions to analyze station log files.
The logs contain entries from different crew members.
Some are corrupted, some are clean.

THREE FUNCTIONS NEEDED:

1. load_logs_from_file(filepath)
   - Read a text file
   - Parse each line into a dictionary
   - Return a list of log dictionaries

2. search_logs(logs, author)
   - Filter logs by author name
   - Return only matching logs

3. sort_logs(logs, key, descending=False)
   - Sort logs by a field (like timestamp)
   - Return sorted list

LOG FILE FORMAT:
  timestamp|author|corrupted|content
  2087-03-15|Dr. Chen|False|Override key: 7734

Each line has 4 fields separated by |
