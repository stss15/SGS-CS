# Level F: First Contact - NPCs

Implement `respond_to_npc()` in `student/player.py`.

## Instructions
1. Open `student/player.py`
2. Add the `respond_to_npc` method
3. It must accept a list of options (engine already prints them)
4. It must ask the user to choose (1-based)
5. It must return the index (0-based)
6. Run `python3 run_game.py` and find the drone in the Main Corridor!

Optional: use your Level E Logbook by calling `record_event` inside `respond_to_npc`.

Note: Encounters can still trigger when you move between rooms. The engine prints combat options; enter a number to choose.
