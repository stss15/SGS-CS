=== HINT 1: Understanding Inheritance ===

GOAL:
Create TWO new classes (Brute and Scout) that INHERIT from Player.

WHAT IS INHERITANCE?
  - A way to create new classes based on existing ones
  - The new class (child) gets all attributes/methods from the old class (parent)
  - You only write the DIFFERENCES

EXAMPLE STRUCTURE (in words):
  - Create a Brute class that inherits from Player
  - In its constructor, call the parent constructor first
  - Then change the stats that are different
  - Add a describe_specialty() method that returns a short description

WHERE TO START:
  1. Open student/player_types.py
  2. Find the template for Brute
  3. Make sure you import Player at the top!
