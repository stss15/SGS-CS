=== HINT 1: Understanding Item Usage ===

GOAL:
Allow the player to USE items from their inventory.
Some items get consumed (med_patch), others stay (keycard).

TWO NEW METHODS NEEDED:

1. Player.use_item(item_name, target)
   - Called by the game when player types "use keycard door"
   - Returns a string describing what happened

2. Inventory.consume(item_name)
   - Removes an item that gets "used up"
   - Like remove(), but specifically for consumables

THE FLOW:
  1. Player types "use med_patch self"
  2. Engine calls player.use_item("med_patch", "self")
  3. Your method checks if player has the item
  4. If not, return an error message
  5. If yes, apply the effect and consume the item
