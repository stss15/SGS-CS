=== HINT 2: Function Patterns ===

LOAD_LOGS_FROM_FILE(filepath)
---------------------------------------------
Steps:
1) Open the file for reading
2) Read each line
3) Split by "|" and build a dictionary
4) Append to a list
5) Return the list

SEARCH_LOGS(logs, author)
---------------------------------------------
Steps:
1) Loop through logs
2) Keep only the ones with matching author
3) Return the matches

SORT_LOGS(logs, key, descending=False)
---------------------------------------------
Steps:
1) Use Python's sorted() function
2) Provide a key function for the field
3) Use reverse=descending when needed

Lambda example (allowed):
  sorted(logs, key=lambda x: x[key], reverse=descending)
