# Level H: Checkpoints - Save & Load

Implement serialisation hooks in `student/player.py`.

## Instructions
1. Open `student/player.py`
2. Implement `to_save_data()` -> Returns a dictionary of player stats
3. Implement `from_save_data(cls, data)` -> Creates a new Player from that dictionary
4. Run `python3 validate.py`
5. Run `python3 run_game.py`, play, type `save`, restart, and type `load`!
