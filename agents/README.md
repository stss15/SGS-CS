# Agents Workspace Guide

This folder is the single source of truth for agent workflows in this repository.

## Core Repo Paths

- Site framework app: `apps/site`
- Shared content adapters: `packages/content-schema`
- Legacy source of truth used by the build pipeline: `src`
- Build scripts currently used: `scripts/build.js`, `scripts/migration/alias-framework-html-routes.js`, `scripts/migration/harden-framework-dist.js`
- Deploy target generated by build: `apps/site/dist`
- Firebase hosting config: `firebase.json`
- Curriculum source materials (`.txt` / `.pdf`): `docs/content`
- Archived/retired files: `archive/repo-cleanup-2026-02-07`

## Daily Commands

```bash
npm ci
npm run framework:build
npm run framework:dev
npm run deploy
```
