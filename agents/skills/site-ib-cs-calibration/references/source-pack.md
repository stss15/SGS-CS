## Usage Rules

- Start with the user-supplied syllabus extract when one exists.
- Use the source-pack files above only as secondary guidance when the task needs repo context.
- For textbook-authoring tasks, read `agent_textbook_skill_guide.md` before making structure decisions.
- For repo file ownership or editing boundaries, defer to `site-content-edit`, `site-layout-patterns`, and `site-architecture-map`.
